## 第八部分 · 推荐系统与 LLM

### 28 LLM 与推荐系统的融合方式

- 推荐系统和 LLM 怎么结合？对话式推荐如何与传统推荐融合？
  1. 在召回阶段，LLM 负责查询理解与改写，利用 LLM embedding 进行语义召回，并实现知识增强的协同过滤。
  2. 在精排阶段，LLM 用于用户兴趣建模、特征交叉的语义增强，并生成推荐理由以辅助打分。
  3. 对话式推荐场景下，Agent 通过多轮交互澄清细粒度需求（如口味、预算、人数），将其转化为结构化查询，交由推荐引擎生成候选结果。
  4. Agent 对推荐结果进行解释，以自然语言说明推荐理由，包括历史行为、评分、距离等因素。
  5. 交互式优化机制中，用户反馈被转换为约束更新，推荐引擎据此重新排序。
  6. 核心价值在于将被动式信息流曝光转变为对话式主动发现。

### 29 基于 LLM 的用户画像（User Profiling）

- 用 LLM 做 User Profiling 的可行性和挑战是什么？
  1. 具体做法是将用户行为序列（浏览、点赞、评论、搜索）转化为自然语言描述，并利用 LLM 生成用户画像摘要。
  2. 该方法的优势在于画像可解释性强，比 embedding 更直观，并能发现协同过滤难以捕捉的兴趣关联。
  3. 成本挑战主要来自亿级用户规模，若每个用户处理数千 token 将难以承受，因此需要分层策略，例如活跃用户实时更新、非活跃用户批量更新。
  4. 时效性挑战体现在用户画像是静态快照，难以实时反映兴趣变化。
  5. 隐私挑战在于行为数据转成文本后可能暴露敏感信息。
  6. 实践中通常将 LLM 画像与 embedding 画像混合使用。

### 31 机器学习基础：GBDT 与集成学习

- 介绍一下 GBDT 算法原理？
  1. 梯度提升决策树采用 boosting 方式，串行训练多棵树。
  2. 每棵新树拟合损失函数的负梯度（伪残差）；在平方损失下负梯度即残差。
  3. 最终预测结果为所有树输出的累加，支持回归与分类任务。
  4. XGBoost 是其工程化改进，加入正则化项、支持并行计算并自动处理缺失值。
