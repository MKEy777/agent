## 第十部分 · 具身智能与物理世界

### 38 LLM Agent 与物理世界的交互

- 具身智能中 LLM Agent 如何与物理世界交互？有哪些核心挑战？
  1. 将自然语言指令分解为子任务序列，例如走到咖啡机、拿杯子、放咖啡豆、按键、端上桌。
  2. 借助机器人视觉识别物体位置与状态，如咖啡机的位置、杯子所在的柜子。
  3. 将语言级决策转换为机器人可执行的动作序列，如 move_to、grip、place 等基元。
  4. 物理世界要求毫秒级反应，而 LLM 推理速度较慢，需采用快反射层与慢规划层分层协作的方式。
  5. 物理动作具有不可逆性（如打碎杯子），因此必须设置安全约束层。
  6. LLM 的物理常识来自文本训练，缺乏真实物理直觉，例如不知道杯子倒过来水会洒。
  7. 仿真环境训练得到的策略迁移到真实环境后，性能会出现下降。

#### 38.1 自动驾驶中的 LLM Agent 角色与限制

- LLM Agent 在自动驾驶这类安全关键系统中能扮演什么角色？有哪些限制？
  1. VLM（视觉语言模型）可用于理解复杂路况，为规划模块提供辅助决策信息。
  2. 人车自然语言交互可编排导航、POI 检索与路线规划。
  3. 对于规则引擎覆盖不到的边界情况，可利用 LLM 推理进行兜底。
  4. 自动驾驶要求毫秒级决策，而 LLM 推理速度较慢，因此只能部署于非实时决策层。
  5. 驾驶行为必须可预测，LLM 的随机性不可接受，需增加确定性校验层。
  6. LLM 决策出错时的法律责任归属尚不明确。
  7. 业界通行做法是由 LLM 负责高层规划，传统算法负责底层实时控制。
